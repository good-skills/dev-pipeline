# Session read cache

Persisted **agent tooling state** for token-efficient pipeline runs. Not product truth — safe to wipe; regenerated by `next` / `task`.

Read with [token-efficiency.md](token-efficiency.md) and [inspect.md](inspect.md).

## File

`docs/dev-pipeline/SESSION-CACHE.md` — **gitignored** (like `agent-prompts/`). Create on first `next` / `task` if missing.

## Before reading any doc path

1. Open `SESSION-CACHE.md` if it exists.
2. If path is in **Loaded** and file not dirty in `git status`, use **Carry-over** text — do not open the file again.
3. Read only paths in **Delta for next handoff** or absent from Loaded.

## Template

```markdown
# Session read cache

**updated_at:** {ISO-8601}
**active_phase:** {PH-ID}
**last_handoff:** {TASK-ID}
**git_head:** {short sha or —}

## Carry-over (stable — paste into next handoff as one-liners)

- **Product identity:** {1–3 lines from PRODUCT.md}
- **SHARED index:** `docs/dev-pipeline/SHARED.md` — contracts: {path list only}
- **Validation:** `{commands from inspect snapshot}`

## Loaded (do not re-read unless file changed or task needs new section)

| Path | Used for | Section / note |
|------|----------|----------------|
| `docs/PRODUCT.md` | TASK-… | full |
| `docs/dev-pipeline/SHARED.md` | TASK-… | authoritative table |

## Delta for next handoff (read ONLY these on next `next`/`task`)

- `TASK-QUEUE.md` row `{TASK-ID}`
- `{epic path}#{feature section}`
- `{new US-* or contract paths not in Loaded}`

## Last prompt paths

- Handoff: `agent-prompts/{TASK-ID}.md`
- Promptize: `docs/promptize-prompts/{TASK-ID}.md` | —
```

## Who updates

| Command | Update |
|---------|--------|
| `/dev-pipeline next` / `task` | After writing handoff: set `last_handoff`, append Loaded rows, refresh Carry-over if PRODUCT/SHARED read, set Delta for **following** `next` |
| `/dev-pipeline adopt` / `backlog` / `brief` / `story` | Refresh Carry-over or clear Loaded rows for paths they changed |
| `/dev-pipeline init` | Create empty cache stub |
| User deletes file | Full re-read allowed next time |

## Delta handoff rules (`next` / `task`)

When `last_handoff` exists and same `active_phase`:

1. Read queue + pick next ready row.
2. Reuse **Carry-over** in prompt body (Product identity, SHARED bullet list) — do not re-read those files.
3. Read epic feature section + any **new** linked `US-*` / contracts not in Loaded.
4. In prompt, optional line: `**Inherited context:** same PRODUCT/SHARED as {last_handoff} unless listed below.`

Implementers: handoff lists exact read order — follow it; do not read full tree.

## Cross-session

New agent/session without chat memory: cache file still avoids re-reading stable PRODUCT/SHARED if `git status` clean and Carry-over present.

Wipe or regenerate when phase switches, `adopt --refresh`, or major SHARED edits.
