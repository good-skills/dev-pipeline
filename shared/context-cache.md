# Session read cache

Persisted **agent tooling state** for token-efficient pipeline runs. Not product truth — safe to wipe; regenerated by `next` / `task` / Promptize.

Read with [token-efficiency.md](token-efficiency.md) and [inspect.md](inspect.md). Promptize reuse: [../promptize/inspection.md](../promptize/inspection.md).

## File

`docs/dev-pipeline/SESSION-CACHE.md` — **gitignored** (like `agent-prompts/`). Create on first `next` / `task` / `/promptize` if missing.

## Before reading any doc path

1. Open `SESSION-CACHE.md` if it exists.
2. If path is in **Loaded** and file not dirty in `git status`, use **Carry-over** text — do not open the file again.
3. Read only paths in **Delta for next handoff** or absent from Loaded.

## Promptize reuse rules

**Normalization (`norm_key`)** — deterministic:

1. Strip leading `/promptize` and flags: `--execute`, `--full`, `--minimal`, `--save`, `--save-to-file` plus a following path argument when present.
2. Lowercase; trim; collapse whitespace; drop surrounding quotes.
3. No stemming, synonyms, or embeddings. Rephrased text = miss.

**Hit:** same `norm_key` **and** row `git_head` equals current `HEAD` **and** body available (`saved_path` exists, or `inline:last` / conversation last body) → reuse rendered prompt; skip inspect / Extract / Specify / Lint.

**Miss:** HEAD mismatch, missing body, or no row → continue Ultra/Micro/delta gate ([../promptize/inspection.md](../promptize/inspection.md)).

**`--execute` on hit:** still run execution revalidation (Touch Set / dirty paths); do not implement stale inventory counts blindly.

**Upsert:** after each successful Promptize Render/Persist, upsert by `norm_key` (update `git_head`, `tier`, path, `updated_at`). Cap **5** rows; drop oldest. Promptize may create the cache file even if `next` never ran. Sync top-level `git_head` when updating.

## Who updates

| Command | Update |
|---------|--------|
| `/dev-pipeline next` / `task` | After writing handoff: set `last_handoff`, append Loaded rows, refresh Carry-over if PRODUCT/SHARED read, set Delta for **following** `next` |
| `/dev-pipeline adopt` / `backlog` / `brief` / `story` | Refresh Carry-over or clear Loaded rows for paths they changed |
| `/dev-pipeline init` | Create empty cache stub (include empty Promptize reuse table) |
| `/promptize` | Upsert **Promptize reuse** row; may create cache stub; update `git_head` / `updated_at` |
| User deletes file | Full re-read allowed next time; reuse table gone |

## Delta handoff rules (`next` / `task`)

When `last_handoff` exists and same `active_phase`:

1. Read queue + pick next ready row.
2. Reuse **Carry-over** in prompt body (Product identity, SHARED bullet list) — do not re-read those files.
3. Read epic feature section + any **new** linked `US-*` / contracts not in Loaded.
4. In prompt, optional line: `**Inherited context:** same PRODUCT/SHARED as {last_handoff} unless listed below.`

Implementers: handoff lists exact read order — follow it; do not read full tree.

## Cross-session

New agent/session without chat memory: cache file still avoids re-reading stable PRODUCT/SHARED if `git status` clean and Carry-over present. Promptize reuse rows with matching HEAD still apply across sessions when `saved_path` points at an existing file.

Wipe or regenerate when phase switches, `adopt --refresh`, or major SHARED edits. Clear or invalidate Promptize reuse rows when HEAD moves materially (or leave them to miss on HEAD mismatch).
